# bench2 results (triangle + cube, in the DroidDeck guest)

Generated by `tools/bench2 --report` from `bench/results.jsonl` (do not edit by hand). Both benchmarks run INSIDE the guest (Linux arm64 glibc under proot) through the Wayland/gamescope path like a game; `ours` = mali-open ICD loaded with `--icd`, `bridge` = the guest's default libvulkan (Mali bridge, MaliDeck version in the row). Values are medians of interleaved runs. Presented = wayland (120 Hz cap), offscreen = headless (no cap): compare drivers on **CPU ms** (record+submit) and **GPU ms** (timestamps), not on capped fps.

Workloads (bench/mdbench): **triangle** = 3000 draws/frame (ours cannot yet do 10k+, see bench/README.md, Known limits), one triangle each, a dynamic-UBO descriptor offset per draw. **cube** = rotating cube + 8 overdraw layers + 24-iteration ALU fragment shader, depth on; `720p` fixed 1280x720, `native` = compositor size (presented), offscreen always 1280x720.
