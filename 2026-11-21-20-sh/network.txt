Network as the session starts
=============================
The SSID is deliberately not recorded, and addresses appear as their kind, not their numbers.

Transport             WiFi
Validated             true   (false with a working link usually means a captive portal)
Metered               false
Link speed            down 115678 kbps / up 72988 kbps
Interface             wlan0
MTU                   0
Addresses             1 IPv4, 1 IPv6
DNS from the system   <private IPv4>
Search domains        none

What the runtime was given
--------------------------
etc/resolv.conf:
    # Written by the app from the device's active network; edits are overwritten.
    nameserver <private IPv4>
    nameserver <public IPv4>
    nameserver <public IPv4>
    nameserver <public IPv6>
    options timeout:2 attempts:2
    

etc/droiddeck-net (the link as the session sees it):
    if wlan0 2 1500
    mac <masked>
    addr <link-local IPv6> 64
    addr <private IPv4> 24
    gw <private IPv4>
    

proot makes no network namespace, so the session uses the phone's connection
directly: IPv4 and IPv6 both pass through, and there is nothing to forward.
Steam reads Android's transport, connectivity and metering through the runtime's
NetworkManager D-Bus bridge. Android settings manage Wi-Fi and cellular connections.
